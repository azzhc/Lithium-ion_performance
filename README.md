# 锂电卫士

## 🧠 项目简介

**锂电卫士** 是一个基于深度学习的交互式平台，可在无需完整充放电测试的前提下，仅通过**短时充电数据**，实现锂电池健康状态（State of Health, SOH）预测及容量增量（Incremental Capacity, IC）曲线获取，进一步进行老化机制量化（如 LAM 分析）。平台支持灵活片段、快速分析、界面操作，适用于电池研究、快充策略分析及工业健康管理等多个领域。

## 🔧 功能概览

### 1. IC曲线获取
- 无需完整充放电实验
- 支持任意片段电压曲线 → 自动预测完整IC曲线
- 支持残差RNN、LSTM、GRU、CNN、ResNet等多模型选择
- 可导出预测曲线结果

### 2. SOH预测
- 基于短时电压序列，估计当前SOH
- 同样支持多模型、参数可调
- 可视化误差指标（RMSE, MAE, R²）

### 3. 老化机制量化
- 支持 LAM（活性物质损失）指标提取
- 基于 IC 峰值强度衰减计算退化程度
- 自动报告生成、量化结果导出

## 📊 技术架构

- **语言环境**：Python 3.8+
- **核心库**：PyTorch, PyQt6, NumPy, Matplotlib, Scikit-learn
- **前端交互**：QtDesigner + PyQt
- **深度模型**：
  - 序列模型：LSTM / GRU / RNN
  - 卷积模型：CNN / ResNet1D（残差结构）
- **数据集**：MIT公开数据集（124块电池，多种快充策略）

## 💡 示例数据

项目提供两个典型快充策略工况示例，位于 `./data` 目录：
- `6C-60per_3C/`: 0-60%SOC为6C倍率 + 60-80%SOC为3C倍率 +80-100%SOC为1C CC-CV
- `7C-40per_3C/`: 0-40%SOC为7C倍率 + 40-80%SOC为3C倍率 +80-100%SOC为1C CC-CV

> 使用这些数据可以直接体验模型训练与预测流程，无需额外准备数据。
